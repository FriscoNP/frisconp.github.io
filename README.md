# frisconp.github.io
This repository containing any content of my github page portfolio website.

A CV and portfolio in a clean, minimal style.

- **Edit content:** `assets/js/cv-data.js`. Any field left as `null` shows as a `???` badge on the page.
- **Preview locally:** `make dev`, then open http://localhost:8080
- **Print / PDF:** use the "Download CV" button (or Ctrl+P). The print stylesheet outputs a plain, single-column CV.
